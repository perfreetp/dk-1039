# 文件关系图分析器 - 产品需求文档

## 1. 产品概述

一款专为产品和运营人员设计的桌面客户端工具，用于梳理项目资料之间的引用关系。通过可视化节点连线图展示文件间的关联，支持文档和图片扫描、智能关系识别、多维度筛选和灵活的关系编辑功能。

- **核心价值**：帮助团队快速理清复杂项目中的文件依赖关系，提升资料整理效率
- **目标用户**：产品经理、运营人员、项目管理者
- **使用场景**：项目启动时的资料梳理、日常资料整理优化、交付前的完整性检查

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限范围 | 核心功能 |
|------|----------|----------|
| 普通用户 | 本地所有功能 | 文件扫描、关系分析、编辑、导出 |

### 2.2 功能模块

1. **主界面**：文件夹选择、文档图片扫描、节点连线图展示
2. **详情侧栏**：文件预览、属性查看、关联来源分析
3. **关系编辑窗口**：新增/合并/删除连线、添加备注
4. **搜索窗口**：孤立文件、重复文件、高关联文件定位
5. **导出界面**：关系图图片、文件清单、待整理建议

### 2.3 页面详情

#### 主界面 (MainView)
| 模块名称 | 功能描述 |
|----------|----------|
| 顶部工具栏 | 文件夹选择按钮、扫描控制、筛选器、搜索入口、导出入口 |
| 关系图画布 | 可缩放/拖拽的节点连线图，支持多种布局算法 |
| 底部状态栏 | 文件总数、关系总数、当前筛选状态 |

#### 详情侧栏 (DetailSidebar)
| 模块名称 | 功能描述 |
|----------|----------|
| 文件预览区 | 图片预览缩略图、文档图标、文件类型标识 |
| 基本信息区 | 文件名、完整路径、文件大小、创建时间、修改时间 |
| 关联来源区 | 列出所有引用当前文件的其他文件 |
| 被引用区 | 列出当前文件引用的所有文件 |

#### 关系编辑窗口 (RelationshipEditor)
| 模块名称 | 功能描述 |
|----------|----------|
| 连线列表 | 显示当前选中的所有关系 |
| 新增关系 | 选择源文件和目标文件创建新连线 |
| 合并关系 | 将多条关系合并为一条并添加备注 |
| 删除关系 | 移除不需要的关系连线 |
| 备注编辑 | 为关系连线添加说明文字 |

#### 搜索窗口 (SearchPanel)
| 模块名称 | 功能描述 |
|----------|----------|
| 关键词搜索 | 按文件名或备注内容搜索 |
| 孤立文件筛选 | 找出没有任何入边或出边的文件 |
| 重复文件检测 | 按文件名相似度或内容hash识别重复 |
| 高关联文件筛选 | 按关系数量排序显示核心文件 |

#### 导出界面 (ExportPanel)
| 模块名称 | 功能描述 |
|----------|----------|
| 关系图导出 | 将当前视图导出为PNG/SVG图片 |
| 文件清单导出 | 导出所有文件的清单（CSV/JSON格式） |
| 待整理建议 | 生成包含孤立文件、重复文件的整理建议报告 |

## 3. 核心流程

### 3.1 文件扫描与关系识别流程

```
用户选择文件夹 
→ 系统递归扫描文档和图片 
→ 解析文件名提及（正则匹配其他文件名） 
→ 识别快捷方式引用（.lnk文件） 
→ 构建文件节点和关系边 
→ 在画布上渲染可视化图表
```

### 3.2 关系编辑流程

```
用户在画布选择文件 
→ 详情侧栏显示文件信息 
→ 用户打开关系编辑窗口 
→ 新增/编辑/删除关系 
→ 添加备注说明 
→ 保存更新图表
```

### 3.3 搜索分析流程

```
用户打开搜索窗口 
→ 选择分析类型（孤立/重复/高关联） 
→ 系统执行分析算法 
→ 结果高亮显示在画布上 
→ 用户可一键导出分析报告
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题色系**：深色专业风格 - 主色 #1a1a2e，辅色 #16213e，强调色 #e94560
- **按钮样式**：圆角矩形，悬停微光效果
- **字体选择**：标题使用 Inter Bold，正文使用 Source Sans Pro
- **布局风格**：左侧主画布 + 右侧可折叠详情栏 + 顶部工具栏 + 底部状态栏
- **图标风格**：线性图标，2px 描边，统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 主要元素 | 交互特性 |
|----------|----------|----------|
| 主界面 | 工具栏、画布、侧栏 | 拖拽缩放、节点拖拽布局、右键菜单 |
| 详情侧栏 | 预览图、信息卡片、关联列表 | 点击跳转、平滑展开收起 |
| 关系编辑窗口 | 模态对话框、关系列表、表单 | 即时保存、批量操作 |
| 搜索窗口 | 搜索框、筛选标签、结果列表 | 实时搜索、点击定位 |
| 导出界面 | 格式选择、预览区、导出按钮 | 即时预览、进度提示 |

### 4.3 响应式设计

- **桌面优先**：主要针对 1920x1080 及以上分辨率优化
- **最小支持分辨率**：1280x720
- **画布自适应**：节点图自动适配容器尺寸，支持全屏展示

## 5. 数据结构设计

### 5.1 文件节点

```typescript
interface FileNode {
  id: string;              // 唯一标识（文件路径hash）
  name: string;            // 文件名
  path: string;            // 完整路径
  type: 'document' | 'image' | 'shortcut';  // 文件类型
  size: number;            // 文件大小（字节）
  createdAt: Date;         // 创建时间
  modifiedAt: Date;        // 修改时间
  preview?: string;        // 预览图base64或路径
}
```

### 5.2 关系边

```typescript
interface RelationshipEdge {
  id: string;              // 唯一标识
  sourceId: string;        // 源文件ID
  targetId: string;        // 目标文件ID
  type: 'mention' | 'shortcut' | 'manual';  // 关系类型
  note?: string;           // 备注说明
  weight: number;          // 关联权重（1-10）
  createdAt: Date;         // 创建时间
}
```

### 5.3 筛选条件

```typescript
interface FilterOptions {
  fileTypes: ('document' | 'image' | 'shortcut')[];
  dateRange: { start: Date; end: Date } | null;
  searchKeyword: string;
  showOrphan: boolean;     // 显示孤立文件
  minRelations: number;    // 最少关系数
}
```
